## Open-redirect / auth conventions (pinned by tests)

- Guest API hits answer 401 JSON; web guests redirect to login (CustomerPageRenderTest, SuspicionAppeal/Journeys).
- Forbidden API answers 403 JSON; web answers 302 with error flash (AdminConsoleRenderTest).
- Unknown URLs return HTTP 404 Inertia page, never soft-200 (web catch-all).
- Turnstile on login/register throttles (BotDefenceTest); uploads throttled (SecurityHardeningTest).
